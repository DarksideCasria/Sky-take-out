# 苍穹外卖 (Sky Takeaway) 🚀

![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.0+-green.svg)
![MySQL](https://img.shields.io/badge/MySQL-8.0-blue.svg)
![Redis](https://img.shields.io/badge/Redis-Latest-red.svg)

**苍穹外卖** 是一款为餐饮企业（餐厅）定制的软件产品，包括系统管理后台和移动端应用。该项目不仅是一个全栈开发的实战案例，更是一个包含外卖业务全流程的数字化解决方案。

---

## 📖 项目简介

本项目模拟了真实的外卖业务场景，旨在提供高效、稳定的在线订餐体验。系统分为两个维度：
1.  **管理端 (Admin)**：供餐厅内部员工使用，用于菜品维护、订单监控、数据分析等。
2.  **用户端 (User)**：基于微信小程序，供消费者浏览菜品、下单支付及查看配送状态。

---

## ✨ 核心功能

### 🛠 管理端 (Management)
* **统计报表**：基于 ECharts 的营业额、用户、订单及销量分析。
* **菜品/套餐管理**：支持分类管理、规格设置、批量启售/停售。
* **订单中心**：实时处理新订单、派送进度管理及历史订单查询。
* **工作台**：核心指标概览，助力经营决策。

### 📱 用户端 (Consumer)
* **微信支付**：深度集成微信支付流程，提供流畅的支付体验。
* **购物车/下单**：动态库存计算与便捷的下单流程。
* **地址簿管理**：支持多收货地址维护。
* **历史订单**：快速再来一单，查看订单物流状态。

## 🛠 技术栈

| 层次 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **后端** | Spring Boot, MyBatis Plus | 核心开发框架 |
| **数据库** | MySQL 8.0 | 关系型持久化存储 |
| **缓存** | Redis | 提升性能，存储验证码及常用数据 |
| **API文档** | Swagger / Knife4j | 在线接口文档及调试 |
| **实用工具** | Lombok, Hutool, JWT | 提升开发效率与安全性 |
| **对象存储** | 阿里云 OSS | 静态资源（图片等）存储 |
| **微信开发** | 微信支付 SDK, 小程序 API | 移动端核心功能支持 |

## 🚀 快速开始

### 1. 环境准备
确保您的机器上已安装：
* JDK 17+
* Maven 3.6+
* MySQL 8.0
* Redis

### 2. 初始化数据库
执行 `sql` 目录下的 `.sql` 文件，创建必要的表结构及初始数据。

### 3. 修改配置
在 `sky-server/src/main/resources/application.yml` 中修改以下配置：
* MySQL 连接信息
* Redis 连接信息
* 阿里云 OSS 参数 (用于图片上传)
* 微信支付参数 (若需本地调试支付功能)

### 4. 启动项目
1.  运行 `SkyApplication` 主启动类。
2.  管理端访问：`http://localhost:8080/doc.html` (Knife4j 接口文档)。
3.  前端部署：根据前端源码指引，启动 Nginx 或微信开发者工具。

## 💡 技术亮点

* **性能优化**：使用 Redis 缓存营业状态及菜品数据，大幅减轻数据库压力。
* **安全性**：通过拦截器（Interceptor）结合 JWT 技术，实现前后端分离下的权限校验。
* **解耦设计**：采用标准的 DTO/VO 分层模型，确保数据传输的安全与精简。
* **异常处理**：全局统一异常处理机制，保证接口返回格式的标准化。
